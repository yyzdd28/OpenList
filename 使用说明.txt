========================================================
  校园健康饮食推荐系统  ·  使用说明
========================================================

【怎么启动】
  双击「校园健康饮食推荐系统.exe」。
  稍等 3-8 秒（首次启动解包会慢一点），
  程序会自动打开浏览器进入学生端登录页。

  屏幕上那个黑色窗口是服务窗口，**不要关闭它**，
  关掉窗口 = 关闭整个系统。

【三个入口】

  学生端        http://127.0.0.1:8000/
                演示账号 zhangxiaoming  密码 Canteen@2026
                登录后「我的勋章 → 编辑名片」可自定义主题、配色和头像，
                保存后得到一个可分享的个人名片网址 /u/你的拼音，
                发给同学或家长就能看到你的勋章墙和健康记录。

  食堂后台      http://127.0.0.1:8000/canteen/login
                初始密码 shitang123456  （建议首次登录后立即修改）

  管理员后台    http://127.0.0.1:8000/admin/login
                初始密码 guanli123456   （建议首次登录后立即修改）

  如果 8000 端口被别的软件占用，程序会自动改用 8001、
  8002……请以黑窗口里显示的实际地址为准。

【密码规则】

  所有由用户设置的密码都必须满足：
      至少 8 位，且同时包含大写字母、小写字母、数字和特殊符号
  例如 Canteen@2026

  注意：食堂后台与管理员后台的初始密码是需求里指定的，不满足这条规则，
  请在首次登录后到「安全设置」里改掉。

【怎么给全校学生用】
  学生端默认只能在本机打开。要让同一个校园网里的学生都能访问：

  1. 把 exe 放在一台长期开机的电脑（或服务器）上运行；
  2. 看黑窗口里显示的另一个地址，形如 http://192.168.x.x:8000/
     （程序启动时也会打印内网地址）；
  3. 把这个地址发到班级群，学生在手机或电脑浏览器里打开即可。
     页面已经做了手机适配：窄屏下会自动变成单列，
     学生在手机上选餐、看评分、发动态都不会挤。

  如果学生打不开，多半是那台电脑的 Windows 防火墙拦了，
  在「Windows 安全中心 → 防火墙 → 允许应用通过防火墙」里
  放行这个 exe 即可。

【数据存在哪】
  数据保存在 exe 同级的 data 文件夹里：

      校园健康饮食推荐系统.exe
      data\canteen.db      ← 全部数据（学生、菜品、积分、论坛…）
      data\secret.key      ← 登录加密密钥

  备份 = 把整个 data 文件夹复制走。
  还原 = 把 data 文件夹放回 exe 旁边。

  ！删除 data 文件夹 = 清空所有数据（下次启动会重新生成演示数据）。
  ！移动 exe 时请连 data 文件夹一起移动。

【首次使用建议顺序】
  1. 进「管理员后台」→ 大模型配置，填 API 地址 / 密钥 / 模型名
     （不填也能用，系统会自动使用内置算法，功能不受影响）
  2. 进「管理员后台」→ 学生管理，把全校学生名单批量导入
     三种方式任选：
       · 直接从 Excel 复制粘贴到输入框（每行一个：姓名,拼音,班级）
       · 上传 .xlsx 文件（表头「姓名/拼音/班级」会自动跳过）
       · 上传 .csv / .txt 文件
     拼音和班级都可以留空：拼音会按姓名自动生成（如「张小明」→
     zhangxiaoming，多音姓氏也能读对），班级套用页面上的默认班级。
     导入后会逐行列出成功/失败原因，成功的可一键复制账号密码发给班主任。
  3. 进「食堂后台」→ 分类管理，确认或补充你们食堂的分类
  4. 进「食堂后台」→ 菜品管理，把食堂的菜录进去（分类必填）
  5. 进「食堂后台」→ 今日菜单，把今天的菜勾选进对应餐次
  6. 学生端刷新即可开始选餐

【积分规则（学生端也能看到）】
  记录一餐按健康度给分：优秀 +10 / 良好 +7 / 及格 +4 / 待改进 +0
  同一个餐次每天只算一次，重复提交不会重复加分；
  但搭配得更健康会把差额补给（鼓励越选越好）。
  使用一键健康搭配本餐次额外 +10（每餐次限 1 次，防连点刷分）。
  家庭做饭实践 +20（每天限 1 次）；美食圈分享 +5（每天限 3 条）。
  以上分值都可以在「管理员后台 → 积分与勋章」里调整。

【常见问题】

  Q: 双击没反应 / 一闪而过？
  A: 用命令行运行 exe，看报错信息；
     最常见原因是杀毒软件误删，把 exe 加入白名单即可。

  Q: 提示端口被占用？
  A: 程序会自动换端口，看黑窗口里的地址就行。
     也可以手动指定：命令行执行  校园健康饮食推荐系统.exe
     或设置环境变量 PORT=9000

  Q: 浏览器没有自动打开？
  A: 手动在浏览器输入黑窗口里显示的地址。
     加 --no-browser 参数可关闭自动打开。

  Q: 大模型填了但没生效？
  A: 在管理员后台点「测试连接」看具体报错。
     不管是密钥错、超时还是网络不通，系统都会自动切回
     内置算法，学生端不会白屏，只是少了大模型润色的文案。

  Q: 想清空数据重新开始？
  A: 关闭程序，删除 data\canteen.db，重新启动即可。
